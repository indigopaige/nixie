#+title:  nixie

* Synopsis
Nixie is a small functional programming language

* Structure
Nixie is structured in a few main parts that are called source components.
Below show these source components and how they work together to build the language.

** Expression
Nixie has many different kinds of expressions

*** Application
#+begin_src
  f x
  f x y
  f x y ... z
#+end_src
*** Lambda
#+begin_src
  x.+ x 1
  x.y.+ x y
#+end_src
*** Let
#+begin_src
  let x = y in z x
#+end_src
*** If
#+begin_src
  if true then x else y
#+end_src
#+begin_src
  both@(x, y)
#+end_src
